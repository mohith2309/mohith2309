### 🚀 What I'm building

**⚡ [Sparky](https://github.com/mohith2309/sparky)** — *a coding platform for kids: my own programming language + a native IDE. Now on 3.0.*
Kids click Scratch-style blocks that type **real text code** in Sparky, an English-like language I designed (`say`, `repeat 10 times`, `teach square length`), then watch it run on a stage with graphics, sound and music. Hand-written tokenizer → parser → interpreter in pure Python, and a fully native PyQt6 IDE for Mac, Windows and Linux, with lessons, Python and Arduino tools, and signed over-the-air updates. No Chromium, no Electron. [Download it here](https://sparky-code.web.app).

**🤖 [MyBot](https://mybot2.web.app)** — *AI teammates with their own computers.*
A free desktop app for Mac, Windows and Linux, written in Rust. You message an AI teammate like a colleague, and it works in its own browser and desktop.

**🧠 [m.ai](https://mai-alus.web.app)** — *a quiet AI workspace, and the home of Spark, my own small AI model.*
Conversations, files and ideas in one place, plus my experiments in training language models from scratch.

**🎓 [CourseForge](https://github.com/mohith2309/courseforge)** — *AI builds your study course from one sentence.*
Type a goal like *"I'm studying for IAS, help me crack it"* and the app generates a full structured course — modules, lessons, narrated text-to-speech video-style player, and quizzes. Offline-first Flutter app + a hardened zero-dependency Node backend on Railway, Firestore datastore, native Razorpay, and a multi-provider LLM chain (Groq → Mistral → GitHub Models) with automatic failover.

**🖨️ [Dittox](https://github.com/mohith2309/dittox)** — *Document printing, simplified.*
Upload your files, find nearby print shops on a live map, place an order, and track it to pickup — all from your phone. Flutter app with a customer side and a print-shop owner dashboard, backed by Firebase (Auth, Firestore, Storage, FCM), Google Maps, and Cloud Functions.

**💸 [GenPay](https://github.com/mohith2309/genpay)** — *Offline-first UPI expense tracker.*
A privacy-friendly Flutter money tracker with on-device AI spending insights and a tiny zero-dependency Node backend. No accounts required, everything stays on the phone.

**🏛️ [Yojana Mitra](https://github.com/mohith2309/yojana_mitra_app)** — *AI assistant for Indian government schemes.*
Helps people discover and understand the schemes they're eligible for, powered by an LLM.

### 🛠️ How I work

- **Apps:** Flutter / Dart, Kotlin / Compose, Rust, Python + Qt
- **Backend:** Node.js (often zero-dependency), REST APIs, HMAC auth, rate limiting
- **AI:** Multi-LLM routing & failover (Groq, Gemini, Mistral, NVIDIA NIM, GitHub Models)
- **Infra:** Firebase / Firestore, Railway, Razorpay payments
- **Hardware:** Arduino, Raspberry Pi, 3D printing, teardowns
- **Focus:** native apps, offline-first, signed updates, shipping real things
